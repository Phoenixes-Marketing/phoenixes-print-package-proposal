# Phoenixes 飲料店平面印刷包套｜公開提案頁

正式網站：<https://phoenixes-marketing.github.io/phoenixes-print-package-proposal/>

這是 Phoenixes 飲料店平面印刷包套的一頁式提案／詢價頁。客戶可查看產品、選擇規格與數量、試算價格並整理詢價摘要，再透過 Phoenixes 聯絡窗口進行正式確認。

## 目前功能

- 中文 Phoenixes Logo、Banner 與響應式手機版。
- 8 個產品圖片、介紹、售價、規格及數量選項。
- 勾選品項後即時計算商品小計、5% 稅金、暫定運費及參考總價。
- 產品卡片標題、說明、價格、選項及刀模按鈕對齊。
- 每項產品保留獨立刀模下載按鈕；尚無正式網址時顯示停用狀態。
- 可複製詢價摘要，並提供 LINE@、服務專線及回官網入口。
- 全寬合約式印刷注意事項。

## 專案邊界

本頁是詢價與需求整理工具，不是線上付款、自動報價、會員、ERP 或自動排印系統。正式規格、價格、交期、檔案檢查與製作安排均由 Phoenixes 團隊確認。

## 資料與安全

- 公開 repo 只保存網站頁面、公開 Logo 與網站顯示需要的 JSON。
- Excel 內容主檔、轉換程式及一鍵更新器保存在私人維護 repo，不會公開。
- 缺少正式資料的規格、圖片與刀模不自行虛構。
- 客製化少量印刷封膜目前採 `130 × 500M`、基本量 6 捲、NT$3,500／捲；此價格不自行套用 66 折。
